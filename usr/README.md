# Hand Gesture Detector

This Flutter application uses the device camera to identify and display human hand gestures.

## Features
- Real-time camera feed
- Mock hand gesture detection ("Thumbs Up", "Peace Sign", "Open Hand")
- Overlay displaying the currently recognized action

## Setup
1. Run `flutter pub get`
2. Run `flutter run` on a real device to test the camera. (Web/simulators may have limited camera support).
